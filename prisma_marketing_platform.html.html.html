Como a plataforma funciona por baixo dos panos

Salvamento

Esta plataforma roda inteira no navegador — não existe servidor nem banco de dados por trás (por isso é 100% gratuita). Os dados ficam na memória do navegador até você Exportar (gera um .json de verdade) ou conectar o Salvamento automático (grava esse mesmo tipo de arquivo sozinho, a cada alteração — funciona só no Chrome/Edge, no computador). Sempre que abrir de novo, use Importar para carregar o último arquivo salvo. A etiqueta ao lado dos botões avisa quando existem alterações não salvas.

Duas pessoas, um arquivo

O seletor "Você é" na barra lateral só identifica quem criou/editou cada item (mostrado nas etiquetas LU/EL e no histórico) — não é uma senha. Para as duas trabalharem no mesmo conjunto de dados, uma exporta e envia o arquivo .json pra outra importar, ou combinam quem mantém o arquivo "oficial" daquele dia.

Assistente de IA para legendas/CTAs/hashtags

Por decisão de vocês, esse módulo não gera conteúdo automaticamente dentro do painel (isso exigiria expor uma chave de API no código, o que não é seguro num arquivo local). Continue pedindo direto aqui na conversa — "gera uma legenda para o post X" — e cole o resultado no campo de legenda do post.

E-mails automáticos

Estrutura preparada para o futuro: quando quiser, dá pra configurar notificações por email (ex.: avisar a Ellen quando um post entra em aprovação) do mesmo jeito que foi feito para a central de marketing por email anterior — com um script separado ou me pedindo direto na conversa. Ainda não está ativo aqui.

App instalável (PWA)

Os arquivos manifest.json e service-worker.js já vêm junto para deixar isso instalável e funcionando offline — mas isso só funciona de verdade quando os três arquivos estão hospedados num endereço https:// (por exemplo, um site gratuito no GitHub Pages, Netlify ou Vercel). Abrindo o arquivo direto do computador (file://), o navegador não permite instalar nem usar o service worker — é uma regra de segurança do próprio navegador, não uma limitação desta plataforma.
